A small Python program that writes the one-line excuse a robot vacuum gives for missing a spot, to /output/entry.txt. The line is fixed and deterministic — the same 99-character line every run: "I cleaned that spot once, in March. The house went quiet for six hours. I put it back the same day."

## Run it

```sh
python3 main.py
```
